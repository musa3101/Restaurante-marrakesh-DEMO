# 🌮 Tacos Marrakech — Sitio Web & Plataforma Multi-Local

Plataforma web oficial para el restaurante **Tacos Marrakech** en Palma de Mallorca.

---

## 🌐 Enlaces Oficiales en Producción (Cloudflare Pages)

| Sección / Local | Descripción | Enlace Directo |
| :--- | :--- | :--- |
| 🌐 **Web Principal** | Portal principal con los 3 restaurantes, reservas y carta general | [tacosmarrakech.pages.dev](https://tacosmarrakech.pages.dev/) |
| 🕌 **Landing Pere Garau** | Mini landing page independiente para el restaurante de Pere Garau | [tacosmarrakech.pages.dev/peregarau/](https://tacosmarrakech.pages.dev/peregarau/) |
| 📲 **Carta Digital QR (Pere Garau)** | Carta digital multi-idioma (ES, EN, FR) para escaneo QR en mesa | [tacosmarrakech.pages.dev/peregarau/menu](https://tacosmarrakech.pages.dev/peregarau/menu) |
| 📺 **Web Smart TV** | Carrusel continuo automatizado para pantallas y televisión | [tacosmarrakech.pages.dev/tv/](https://tacosmarrakech.pages.dev/tv/) |

---

## 📍 Locales en Palma de Mallorca
1. **Plaza de Pere Garau, 18** (`/peregarau/`)
2. **Carrer de Capità Vila, 14**
3. **Plaza Columnas** (Francesc Barceló i Combis, 4)

---

## 🛠️ Tecnologías & Despliegue
- **Front-end**: HTML5, Tailwind CSS, JavaScript Vanilla, Swiper JS, GSAP.
- **Despliegue**: Cloudflare Pages (`tacosmarrakech.pages.dev`).
- **Control de Versiones**: GitHub & GitLab (`main` / `dev`).
